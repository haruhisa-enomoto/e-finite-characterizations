Subject structure of EFiniteCharacterizations/

The Lean package is organized strictly by mathematical subject inside a single EFiniteCharacterizations namespace, with Mathlib as its sole external dependency. Every file uses the Lean 4 module system.

Adapted foundational modules

Twenty-four foundational modules (on Nakayama functors, linear duals, balanced tensor products, contragredient duality, split basic corners, composition length, and Farkas's lemma) were ported from earlier Apache-2.0 formalizations and unified into the topic layout above; see VENDORED.md and verification/module-origins.json for module-by-module attribution.
